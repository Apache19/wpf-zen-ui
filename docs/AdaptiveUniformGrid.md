# AdaptiveUniformGrid

`AdaptiveUniformGrid` 继承 WPF `UniformGrid`，增加固定行列间距和按原始行分组的拉伸布局，不需要主题资源或控件模板。

```xml
<ui:AdaptiveUniformGrid
    xmlns:ui="http://schemas.thezendev.com/wpf/2027"
    Columns="3"
    RowSpacing="8"
    ColumnSpacing="12"
    IsRowStretchEnabled="True">
    <Button Content="A" />
    <Button Content="B" Visibility="Collapsed" />
    <Button Content="C" />
    <Button Content="D" Width="100" Height="32" />
    <Button Content="E" />
</ui:AdaptiveUniformGrid>
```

这里 A、C 平分第一行，D、E 平分第二行的布局槽位，两行内部均保持 12 DIP 的槽位间距。D 仍然遵循自己的 `Width="100"`、`Height="32"`，不会被面板强制改成槽位大小。

| 属性 | 默认值 | 行为 |
| --- | --- | --- |
| `RowSpacing` | `0` | 行槽位之间的间距，必须为有限非负数 |
| `ColumnSpacing` | `0` | 同一行中槽位之间的间距，必须为有限非负数 |
| `IsRowStretchEnabled` | `true` | 同时启用保留行分组、折叠整行移除和末行拉伸；关闭后按 UniformGrid 连续补位并保留末行空格 |
| `Rows`、`Columns` | `0` | 继承 UniformGrid 的行列设置；0 表示自动计算 |
| `FirstColumn` | `0` | 增强模式下完全忽略；关闭增强后作为首行起始列使用，始终保留配置值和绑定 |

增强模式以全部直接子项（含 `Collapsed`）确定行列分组。例如 `Columns="3"` 时，每三个原始子项构成一行，只有末行可以不足三个；`FirstColumn` 不参与分组或行列数计算。某行折叠一个项目时，其余两个平分整行；折叠两个时，剩余一个占满整行。原始行成员不变，后续行的项目不会跨行补位。`Hidden` 仍占空间。整行子项都变为 `Collapsed` 时，才移除该行和相应的行间距，后续行整体前移；恢复可见后回到原始分组。集合增删或行列设置变更会重新分组。

每一行内部槽位等宽，所有保留行等高。各行非折叠项目数不同时，分配给这些项目的槽位宽度可以不同，这不会改变各行的原始项目数量。指定的 `Rows` 和行列均为自动时的正方形网格仍会保留尚未分配子项的空行；只有包含子项且这些子项全部折叠的行会被移除。增强模式下没有任何非折叠子项时，期望大小为零。若需要按实际项目自动生成行，建议显式指定 `Columns` 并保持 `Rows="0"`。

固定行列数不足以容纳所有子项时，与 UniformGrid 一样，超出容量的子项会继续排到网格下方。增强模式只从高度分配行数中扣除原本位于网格容量内的整行折叠；溢出行整体折叠不会改变前面各行的高度。如果网格容量内的项目全部折叠但仍有溢出项目可见，则至少保留一份行高，供前移后的可见行使用。

面板通过正常的 WPF `Measure` / `Arrange` 分配槽位，不写入子项的尺寸、边距或对齐属性。子项的 `Width`、`Height`、最小／最大尺寸、`Margin`、水平／垂直对齐、布局裁剪仍由 WPF 处理。间距描述的是**布局槽位之间的距离**：子项使用固定尺寸、边距或非拉伸对齐时，实际可见边缘之间的距离可以更大。空间不足以容纳间距时，槽位尺寸最小为零，间距不会被缩小。

关闭增强模式后，无论间距是否为零，均采用 UniformGrid 的行列计算、折叠补位和末行留空规则。`FirstColumn` 仅在小于显式指定的 `Columns` 时有效；无效时只在布局计算中按零处理，不改写属性值或绑定。调整 `Columns` 使其有效后，原配置会重新生效。增强模式始终忽略该属性，关闭增强后恢复按上述规则使用。测量与排列由面板自身完成，以避免原生 UniformGrid 在测量时写回无效 `FirstColumn` 而清除绑定。换行按整数列计数判断，即使槽位小于 1 DIP，也不会因原生实现的坐标容差而提前换行。

子项在首次测量时会应用模板；模板初始化、触发器或绑定可能在此时修改直接子项的 `Visibility` 或面板的行列、间距、拉伸设置。面板会记录这些变化并立即重新测量一次，保证一次性初始化后的分组、期望大小和排列一致。如果第二次测量仍有变化，则在排列阶段请求后续 WPF 布局轮次，避免在单次测量中无限重试。子项的布局相关逻辑必须最终稳定，不应随每次测量约束变化反复切换这些设置；测量期间直接增删面板子项不受支持。

支持在 `StackPanel`、`ScrollViewer` 等场景中接收无限测量约束，返回的期望大小始终采用有限值。间距累加、尺寸乘法和位置计算发生浮点溢出时，结果会限制为 `double.MaxValue`；这项保护避免无穷或无效数值进入布局，并不意味着屏幕能够显示如此大的坐标范围。

作为 `ItemsControl.ItemsPanel` 使用时，应在 **ItemContainerStyle** 上控制容器的 `Visibility`；只折叠 `DataTemplate` 内部内容不会折叠面板的直接子项。此面板不提供虚拟化。
