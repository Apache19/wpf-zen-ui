# WPF 机制回归重构路线图

这份路线图用于记录 Wpf.Ui 逐步回归 WPF 正统机制的重构工作：
样式、模板、附加属性、资源词典，以及通过显式开关合并到应用级资源的原生控件样式。

## 指导原则

- [ ] 只有当控件提供真实的行为契约、状态模型、服务协作或原生 WPF
      控件难以通过样式和模板表达的交互模式时，才保留 Wpf.Ui 自定义控件类型。
- [ ] 只有外观变化时，优先使用原生 WPF 控件加样式。
- [ ] 图标、描述文本、占位文本、圆角、徽章、紧凑视觉标记等可复用模板参数，
      优先使用附加属性表达。
- [ ] 不要静默地把 Wpf.Ui 样式全局应用到原生 WPF 控件上。
      原生控件的全局样式必须有可显式选择启用/关闭的开关。
- [ ] 将 `ThemeManager.EnableNativeControlStyling` 作为把原生 WPF 控件样式合并到
      `Application.Resources` 的公开开关。
- [ ] 将自定义控件样式、原生控件标准样式、主题资源和辅助附加属性分开放置。
- [ ] 保留用户自定义样式、模板和本地属性值的优先级。库里的辅助逻辑不应覆盖用户的显式选择。

## 资源与主题结构

- [ ] 将 Wpf.Ui 自定义控件样式与原生 WPF 控件样式分离。
- [ ] 除非只服务于 Wpf.Ui 控件模板，否则不要把原生 WPF 隐式样式放进 `Generic.xaml`。
- [ ] 将面向应用全局使用的原生 WPF 隐式样式移动到 `Standard.xaml` 这条显式启用路径。
- [ ] 让 `EnableNativeControlStyling` 只负责合并原生控件标准样式包。
- [ ] 确保标准样式资源词典可以安全地合并到应用级资源。
- [ ] 避免使用通过反射或其他隐藏全局副作用来套用样式的 loader 资源词典。
- [ ] 当已发布的 XAML 不再引用兼容 loader 后，删除它们或标记为过时。

## 附加属性层

- [ ] 为共享视觉元数据设计一组小而清晰的附加属性。
- [ ] 添加可用于原生 `Button`、`MenuItem`、`ComboBoxItem`、`ListBoxItem`
      等控件的图标附加属性。
- [ ] 只有当多个控件都能复用时，才添加新的可选附加属性。
- [ ] 优先使用按领域划分的辅助类型，例如 `IconAssist`、`TextBoxAssist`
      或 `MenuItemAssist`，避免做成一个巨大的杂物袋。
- [ ] 文档化哪些附加属性属于稳定公开 API。
- [ ] 添加样式示例，展示模板部件如何绑定到附加属性。

## 待审查控件

- [ ] `MenuItem`：如果图标支持可以由附加属性和原生 `MenuItem` 样式解决，
      就移除自定义控件类型。
- [ ] `Menu`：只有在提供超出原生 `Menu` 的行为时才保留；否则迁移为原生 `Menu` 样式。
- [ ] `ContextMenu`：优先使用原生 `ContextMenu` 样式；只有存在明确行为差异时才保留
      `ui:ContextMenu`。
- [ ] `TextBox`：拆分纯视觉样式与清除按钮、占位文本、文本选择模式等行为。
- [ ] `ComboBox`：分离可编辑文本框样式与 ComboBox 自身行为。
- [ ] `PasswordBox`：只有命令处理、密码显示等功能确实需要时才保留自定义行为；
      能用标准样式表达的部分走原生控件样式。
- [ ] `DatePicker` 和 `TimePicker`：移除自定义右键菜单 Setter，并审查内部可编辑部件能否使用标准文本样式。
- [ ] `NumberBox`：区分哪些是真正的行为，哪些只是标准文本输入外观。
- [ ] `DataGrid`：分离原生编辑控件样式与 Wpf.Ui 特有的 DataGrid 行为。

## 右键菜单专项

- [ ] 对应使用 WPF 原生编辑菜单的可编辑控件，移除显式 Copy/Cut/Paste `ContextMenu` Setter。
- [ ] 让 WPF 文本编辑控件保留原生右键菜单行为，使键盘 Menu 键触发的位置跟随光标。
- [ ] 通过资源词典为原生 `ContextMenu`、`MenuItem` 和 `Separator` 提供样式，
      不再依赖运行时反射。
- [ ] 原生右键菜单样式面向应用全局生效时，必须通过 `UseStandardControlStyles` 显式启用。
- [ ] 验证 `TextBox`、可编辑 `ComboBox`、`RichTextBox`、`PasswordBox`
      和 DataGrid 编辑器中的鼠标右键与键盘 Menu 键定位。

## 兼容与迁移

- [ ] 提供从纯视觉 `ui:*` 控件迁移到原生控件加 Wpf.Ui 样式和附加属性的说明。
- [ ] 对会造成破坏性变更的控件，暂时保留过时包装控件。
- [ ] 只有在替代样式和附加属性准备好之后，才把纯视觉包装控件标记为过时。
- [ ] 为库自定义控件和启用标准样式的原生 WPF 控件分别添加示例。
- [ ] 逐步更新 Gallery 示例，让它们在合适场景展示推荐的原生控件用法。

## 验证清单

- [ ] 为所有目标框架构建 `src/Wpf.Ui/Wpf.Ui.csproj`。
- [ ] 测试存在和不存在 `Application.Current` 时的资源查找。
- [ ] 测试启用和未启用 `UseStandardControlStyles` 时的资源查找。
- [ ] 测试 `Popup`、`ContextMenu`、`Frame` 和 WinForms `ElementHost`
      宿主场景中的控件表现。
- [ ] 替换包装控件后，检查键盘导航、焦点视觉、自动化对等体和命令路由。
- [ ] 确认用户提供的样式和本地属性值仍然优先于库默认值。
