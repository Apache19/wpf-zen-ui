# SoftKeyboard 检查记录

检查日期：2026-09-11。范围为当前工作区的软键盘实现、相关模板、AutomationPeer、文档与测试，包括尚未提交的布局架构重构。

## 已修复的问题

| 问题 | 触发条件与影响 | 修复与验证 |
| --- | --- | --- |
| 延迟 IME 操作脱离原输入会话 | 请求取消组合后，在 Dispatcher 执行操作前切换编辑器，旧操作可能改变新编辑器的输入模式；关闭后重开也可能继续执行 | 使用会话版本与目标/焦点校验，目标变化、关闭、隐藏、禁用、卸载、窗口失活后拒绝旧操作。新增五种状态切换回归用例，包括往返切换 |
| 替换目标适配器后布局过期 | 新适配器识别同一个编辑器，但返回不同 InputScope，ActiveTarget 的属性回调不会触发 | 更换适配器时主动重建布局；验证添加及移除适配器后上下文立即更新 |
| 公开头部属性未接入模板 | HeaderHeight、HeaderContent、HeaderContentTemplate 设置后不生效 | 默认模板绑定固定高度，并在无候选时显示头部内容；验证内容、模板、高度更新和候选切换不移动键区 |
| 无效输入载荷进入不可变模型 | 虚拟键没有有效 Key，文字键没有文字，或备选项为空，用户点击后无输入 | 构造时拒绝无效载荷，布局提供器可及时得到异常；保留带可读标签的空格、制表符输入 |

## 检查覆盖

- 布局：语言/场景/页面组合顺序、null 委托、默认回退、错误诊断、开放页面标识、布局快照及网格边界。
- 输入：可编辑性、目标作用域、焦点恢复、前台窗口校验、一次性 Shift、重复键、直接文字与组合取消、自定义动作上下文失效。
- 生命周期：加载/卸载、显示/隐藏、禁用、窗口失活、模板替换、计时器与弹出层清理。
- IME：状态读取与适配器降级、配置切换观察、候选文档归属、候选选择/翻页、原生候选恢复、COM 与反射失败路径。
- 展示：面板测量和排列、长按备选项、候选滚动与选择、头部保留空间、模板绑定、UI Automation 的名称与 Invoke。
- 集成：核心库与 Gallery 的目标框架构建、现有文档契约与默认模板一致性。

本地 WPF 源码确认：InputMethod.Current 在已有 Dispatcher 的线程上按需创建实例，因此控件 Loaded 中的原空值 TODO 不成立，已改为准确说明。

## 当前边界与后续实机验证

以下内容不能由这次测试证明已完整支持：

- 两项显式测试需要真实前台 SendInput 或已安装的微软拼音；本次未运行，也未执行真实日语/第三方 IME 全流程测试。
- 当前前台窗口检查依赖 WPF Window。WinForms ElementHost 等无 WPF Window 的宿主需要独立宿主句柄设计，当前不应视为已支持。
- 默认头部设置按钮仍是模板中的占位功能，没有设置菜单实现。
- 日语内置布局是现有紧凑布局策略，并不等于 Win11 触摸键盘的完整日语面板实现；架构允许整体替换。
- 真机触摸/手写笔、多指、硬件修饰键同时按下、混合 DPI、屏幕阅读器与不同 Windows/IME 版本仍需实机验证。
